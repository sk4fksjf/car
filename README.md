# ХОД — каршеринг представительского класса

Чистые HTML/CSS/JS без сборки. Плавный скролл — библиотека Lenis с CDN
(без интернета сайт работает с обычной прокруткой).

```
index.html
css/style.css
js/main.js                        ← машины, тарифы, логика роликов
assets/video/s-class-to-bmw7.mp4  ← S-Class уезжает, приезжает BMW (без звука)
assets/video/bmw7-to-s-class.mp4  ← BMW уезжает, возвращается S-Class (без звука)
assets/img/*.jpg                  ← кадры из роликов: постеры и фото в автопарке
```

Открывать лучше через любой локальный сервер (или сразу на хостинге):
браузеру нужна поддержка Range-запросов, чтобы перематывать видео.

## Как работает стрелка

Ролики стыкуются в кольцо: каждый начинается с машины, на которой закончился
предыдущий. По клику играет текущий ролик, на моменте полной остановки
ставится на паузу, а следующий ролик незаметно подменяется поверх.

Тайминги в `js/main.js`, массив `CLIPS` (секунды исходного ролика):

- `from` — откуда стартовать (до этого машина просто стоит);
- `swap` — когда в кадр въезжает следующая машина (меняется подпись);
- `to` — когда она остановилась (пауза).

- `align` — поправка на стыке роликов: на сколько сдвинуть, увеличить и
  подсветить первый кадр, чтобы он совпал с последним кадром предыдущего
  (замерено по кадрам). Поправка плавно уходит, пока машины едут.

`RATE` — скорость воспроизведения. 1.25 выбрана не случайно: 24 кадра × 1.25 =
30 кадров/с ровно ложатся на экран 60 Гц, движение без подёргиваний.
Если меняете — берите 1 или 1.25. Перед остановкой ролик сам замедляется.

## Добавить третью машину

1. Нужны ролики, которые замыкают кольцо, например
   BMW → Новая и Новая → S-Class (вместо текущего BMW → S-Class).
2. Добавьте машину в `CARS`, а ролик — в `CLIPS` в том же порядке.
3. Добавьте `<video data-clip="2">` в hero в `index.html`.
